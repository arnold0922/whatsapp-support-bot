Key decisions

  • Simulated AI. Keyword matching is free, needs no API key and always works in a demo.
  • A person is always one tap away. "Talk to a human" shows after every answer, and unknown questions offer a handoff instead of a guess.
  • FAQs kept apart from the code. To change the questions or answers, you edit only faq.js.
  • Plain HTML, CSS and JavaScript. Nothing to install, quick to load, easy to read.

AI tools used

Claude Code helped plan the features, write the code and draft the documentation. Every choice was reviewed and approved before it was built.

What I'd improve next

  1. Use a language model that answers only from the FAQs, and hands off when it isn't confident.
  2. Connect to the WhatsApp Business API and a support inbox for real staff.
  3. Give staff a short summary of the chat at handoff.
  4. Log unanswered questions to see which FAQs to add next.
